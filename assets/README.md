# Project Assets & Architectural Resources

This directory contains visual assets, system architecture diagrams, and design documents.

## Available Assets

- **System Architecture Diagrams:** Block diagrams illustrating the end-to-end processing pipeline from raw radiograph ingestion to factual caption generation.
- **Reference Documentation:** Full architectural design specifications in PDF and Word formats (`Bone_Fracture_System_Architecture.pdf`, `Bone_Fracture_System_Architecture.docx`).
- **Reports & Plots:** Calibration curves, confusion matrices, and empirical validation figures located in the [`reports/`](../reports/) directory.
